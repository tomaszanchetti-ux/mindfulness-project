# M5 — Compartir

El único canal de crecimiento — y el más delicado. Regalar por link una carta sola o un
ejercicio completo; quien recibe lo abre **sin instalar nada, sin login**, y vive el momento al
instante.

| Archivo | Qué es |
|---------|--------|
| [`Madre_del_Motor.md`](Madre_del_Motor.md) | La lógica completa de Compartir, en cristiano. **Fuente de verdad.** |

**En una línea:** el link es un **regalo completo, no un embudo** — recibir no requiere
instalar. Dos modos: **carta sola** (sin datos tuyos) y **ejercicio completo** (con reflexión +
fotos → aviso de privacidad explícito). Token opaco en la URL, página pública server-side, un
solo CTA suave al final. **El link muere si borrás la entrada** (M4 lo apaga). Tabla nueva
`compartidos`. **Secundario y latente: se ofrece, nunca se empuja.**

Se rige por el [`Documento Madre`](../00_Documento_Madre.md). Lo exponen [M3](../M3_Ritual/) (al
cerrar) y [M4](../M4_Baul/) (sobre una entrada); el CTA del receptor lleva al onboarding
([M1](../M1_Onboarding_y_Perfil/)). Todavía es **lógica**, sin codear.
