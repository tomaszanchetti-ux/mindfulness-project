# Mindfulness App

App de **micro-rituales diarios de presencia, gratitud y conexión humana**. El
usuario logra, al menos una vez por día, una actividad real de desconexión **fuera
del teléfono**; el teléfono es **guía** (le trae la consigna) y **baúl** (guarda el
rastro), nunca el destino.

> Stack objetivo: Google Cloud + base de datos relacional + buen front (nivel Arc
> One). Plataforma v1: Web / PWA. Compartir por link = función secundaria y latente.
