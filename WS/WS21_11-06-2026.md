# WS21 · 11/06/2026 — El aviso diario pasa a PUSH WEB (notificación en el teléfono)

> Pregunta de Tomás post-WS20: "¿si o sí email? ¿no podemos notificar vía PWA?"
> Decisión: **SOLO push** (sin email, chau SendGrid — no hace falta crear nada).
> Consecuencia asumida: quien no instala la app / no acepta el permiso, no recibe
> aviso → onboarding y Perfil empujan a instalar+activar (sinergia con WS19).

## Cómo funciona

Web Push **estándar + VAPID** (sin FCM, sin terceros, $0). El barrido de WS20
queda intacto — solo cambió el canal de salida:

- **Llaves VAPID** generadas localmente (EC P-256): privada en
  `.deploy/vapid_keys.env` (gitignored) + env Cloud Run `MINDFUL_VAPID_PRIVATE_KEY`
  (vacía = push apagado, dev/tests); pública hardcodeada en `lib/push.ts` (es
  pública por diseño). Sin pasos de consola.
- **Backend:** dep nueva `pywebpush==2.1.2` · tabla **`push_suscripciones`**
  (usuario_id, endpoint único global, p256dh, auth; migración `a8b9c0d1e2f3`) ·
  `services/push.py` (`enviar_push` → ok/gone/error/off; 404/410 = "gone" → se
  borra la fila) · `routers/push.py` `POST /api/push/suscripcion` (upsert por
  endpoint; si reaparece con otro dueño se REASIGNA — el dispositivo es de quien
  está logueado) + `POST /api/push/baja` (solo el dueño) · `aviso.py` ahora empuja
  a TODAS las suscripciones del usuario; **sin dispositivos NO estampa la fecha**
  → si activa las notificaciones más tarde ese día, el aviso del día le llega
  igual. TTL 12h. `services/email.py` queda dormido (posible respaldo futuro).
- **Front:** `public/sw.js` + handlers `push` (showNotification con ícono) y
  `notificationclick` (enfoca/abre `/hoy`) · `lib/push.ts` (soporta/permiso/
  activar/desactivar; el subscribe manda la suscripción a la API) · **Perfil ›
  Tu pausa diaria** = bloque de estado por dispositivo (activas ✓ · botón
  "Activar notificaciones" · iPhone-sin-instalar → instructivo · bloqueadas →
  ajustes del sistema) · **Onboarding paso Aviso**: pide el permiso DENTRO del
  toque "Crear mi ritual" (los navegadores lo exigen) + nota para iPhone.

## Realidad por plataforma (por qué el empujón a instalar)

Android/desktop: anda en el navegador. **iPhone: SOLO con Dwellia instalada en
la pantalla de inicio (iOS 16.4+)** — en Safari suelto la API no existe. Por eso
el copy del Perfil conecta con el instructivo de instalación (WS19).
